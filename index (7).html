About me

I'm a full-stack developer who is passionate about building high-quality web applications, with a strong commitment to best coding practices through Clean Architecture, sound design principles and proven design patterns. I focus on building secure, scalable APIs, backed by solid experience in authentication, authorization and relational databases. My frontend skills are still growing, and I'm actively developing them.

My strongest work so far is my graduation project, Hanshtabhalk, a live platform that connects apartment owners with craftsmen and stores. I built its REST API, SQL Server database and admin dashboard, secured with JWT and ASP.NET Identity, Twilio OTP verification and full Arabic and English support. I rely on patterns like Generic Repository, Unit of Work and the Specification Pattern, with Serilog logging, pagination and global exception handling, so the code stays production-ready.

I graduated in Physics and Computer Science from Menoufia University in 2025, completed the 120-hour Full Stack .NET program at ITI, and I'm now part of the Digital Pioneers scholarship. My goal is simple: write clean, maintainable code and deliver it on time, in a way that meets and goes beyond what clients expect.
